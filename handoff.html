ホームページ提案プレビュー
実装ガイド

株式会社プレジャーデサイン様のホームページ リニューアル案を、そのまま実装に使っていただくための手引きです。作成：株式会社コミクス（2026年11月12日）

プレビューを開く 素材一式（ZIP）をダウンロード ファイルを1つずつ見る

最短の進め方

  1. ZIP をダウンロードして展開し、index.html をブラウザーで開く（サーバー不要・そのまま表示できます）。
  2. 下の「公開前に必ず直す箇所」を上から順に対応する（プレビュー用の表示とダミーのフォームを本番用に差し替える）。
  3. 現行サイトの各ページへのリンクをつなぎ、表示を確認して公開する。

前提

  • 外部の読み込みはゼロです（CDN・Web フォント・計測タグ・ライブラリなし）。ビルド作業もありません。
  • フォントは端末の標準フォント（游ゴシック／ヒラギノ／メイリオ）です。
  • 画面幅の切り替えは 1180px・960px・740px・359px の4段階です。
  • 掲載した文章と会社概要は、2026年11月12日時点の現行サイト（トップと会社概要ページ）の記載だけを使っています。実績の数字やお客様の声など、現行サイトで確認できなかった内容は入れていません。

お問い合わせフォームのつなぎ方

方法A：現行のお問い合わせページへ送る（いちばん早い）

フォーム部分（index.html 137〜150行目の <div class="form-panel">）を、現行の /contact/ へ進むボタンに置き換えます。ヘッダーや各事業カードのボタン（href="#contact"）はそのまま使えます。 

<div class="form-panel">
  <a class="button button-large" href="/contact/" data-cta="contact">
    お問い合わせフォームへ<span class="arrow" aria-hidden="true">↗</span>
  </a>
</div>

このとき app.js の 68〜122行目（フォーム用の処理）は不要になるので削除します。残すと、フォームが見つからないというエラーがブラウザーのコンソールに出ます。あわせて index.html 136行目の「プレビュー用フォーム」の注記（<div class="contact-demo-note">）も削除してください。

方法B：このページのフォームをそのまま使う

  • index.html 138行目：action="#contact" を実際の送信先に変え、method="post" と各入力欄の name 属性を足す（プレビューでは name を付けていません）。
  • index.html 136・139・146行目：「プレビュー用フォーム」「外部へ送信・保存されません」「デモ動作のみ」の文言を削除する。
  • index.html 140〜143行目：autocomplete="off" を name・organization・email・tel に変える（入力の手間が減ります）。
  • index.html 145行目：ボタンの文言「入力内容を確認する」を「送信する」などに変える。
  • app.js 102行目：event.preventDefault(); が送信を止めています。入力に不備があるときだけ止めるように変え、116〜118行目の「送信されていません」の表示を外す。
  • 迷惑送信の対策（reCAPTCHA など）と、送信後の完了ページを用意する。

事業カードの「この事業について相談する」を押すと、お問い合わせ内容の欄に事業名が自動で入ります（app.js 74〜90行目）。方法Bではそのまま使えます。

立体感のあるオレンジのボタン

ボタンだけを現行サイトへ先に取り入れる場合は、この3行で再現できます（styles.css 60〜62行目）。下側の濃い影で厚みを出し、押すと沈みます。 

.button { display: inline-flex; min-height: 56px; justify-content: center; align-items: center; gap: 32px; padding: 14px 26px; color: #fff; background: linear-gradient(180deg, #FF7A00 0, #E85E00 3px, #c95000 3px, #bd4d00 100%); border: 0; border-radius: 7px; box-shadow: 0 4px 0 #a54200, 0 9px 18px rgb(90 45 10 / 12%); font-size: 16px; font-weight: 700; line-height: 1.5; text-shadow: 0 1px 1px rgb(100 35 0 / 15%); transition: transform .2s, box-shadow .2s; }
.button:hover { transform: translateY(-2px); box-shadow: 0 6px 0 #bd4d00, 0 12px 22px rgb(90 45 10 / 16%); }
.button:active { transform: translateY(3px); box-shadow: 0 1px 0 #bd4d00, 0 4px 9px rgb(90 45 10 / 12%); }

各ボタンには data-cta（header／hero／services／form-preview）を付けてあります。計測タグを入れたあと、どのボタンが押されたかを見分けるのに使えます。

WordPress に組み込む場合

現行サイトは WordPress（テーマ名 pleasuredesign）とお見受けしました。組み込む際の目安です。

  • index.html の <header> と <footer> をテーマの header.php／footer.php へ、<main> の中身をトップページ用のテンプレートへ移します。
  • styles.css は .button・.container・.hero・.field など一般的なクラス名を使っています。現行テーマの CSS と同時に読み込むと干渉する可能性があるので、トップページだけで読み込むか、クラス名に接頭辞を付けてください。
  • app.js は <head> で defer 付きで読み込んでいます。フッターで読み込む形に変えても動きます。
  • ロゴの参照先 assets/logo.png は、現行の /images/logo01.png に変えれば画像の追加は不要です。
